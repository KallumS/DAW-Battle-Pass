# Writing Battle Pass colours

The family's house scheme warmed to plum: the same roles, greys with a
little red and blue in them (R ≈ B > G) instead of the cool blue-greys. Kept
by hand: change a colour in `Theme.swift` or `Rarity.swift`, change it here.

| | value | what it is |
| --- | --- | --- |
| Accent | `#FFF200` | whatever is on: the chosen tab, the clock while it runs, a quest to claim, "Sure?", an XP Boost's stripes, the next tier |
| Controls | `#BDB3C6` | buttons |
| Ground | `#26212B` | the window |
| Ink | `#1A161E` | the text on every button |
| Sunken | `#1D1922` | panels and cards |
| Deep | `#15121A` | bars' empty part, tiles |
| Rule | `#3B3443` | separators, empty slots |
| Grab | `#5A5163` | the clock's ring while paused |
| Body text | `#EDE7F0` | (also Common) |
| Dim text | `#948B9C` | (also Poor) |
| Bright | `#F7F3F9` | the level number |
| Warn | `#E0485A` | the dot on a tab with something waiting |

The rarity ladder is DAW Battle Pass's, unchanged from Uncommon up:
Uncommon `#3FCF6E`, Rare `#3D8EFF`, Epic `#A45CFF`, Legendary `#FF8A1C`,
Mythic `#FF3FA4`. XP is Rare's blue, the pass Legendary's orange, coins gold
`#FFC83D` with an edge of `#B9862A`. The permission slip is the one place
with paper colours (`#F6EBD6`, ink `#2B2118`), because it is a piece of paper.
