# 2026-10-22 - Writing Battle Pass

## Asked for

A friend wanted one for her writing: repurpose DAW Battle Pass for a woman in
her thirties who writes, with rewards tailored to make-up and buying clothes
(her examples), XP for every letter typed but not scaled too highly, and -
the big difference - a standalone app for an Apple silicon Mac.

## The route

1. **Choosing what to build it in** ([0018](../decisions/0018-the-writer-is-a-native-mac-app.md)).
   LÖVE would have reused the Lua engines and been screenshot-able here, but
   counting typing in other apps, a menu bar clock and login items would all
   have gone through LuaJIT's FFI. Swift and SwiftUI won; the rules were
   ported to a pure-Swift `PassCore` in the Lua engines' shape.
2. **No Swift here.** The container can't download a Swift toolchain
   (download.swift.org is refused by the proxy), and Swift on Linux couldn't
   build AppKit anyway. GitHub Actions on `macos-15` became the compiler,
   test runner and packager, with a `--snapshots` mode that draws every page
   to PNG.
3. **The engine**, retuned: letters and words from a key-count tap
   ([0019](../decisions/0019-typing-is-counted-never-recorded.md)), 0.1 XP a
   letter capped at 30 a minute ([0020](../decisions/0020-letters-are-a-top-up.md)),
   fifteen-minute sprints, word milestones, a wardrobe of eight slots (pen,
   lipstick, perfume, jewellery, outfit, shoes, handbag, desk charm), thirteen
   kinds of writing prompt, writerly titles and seasons, and fourteen treats
   she can edit ([0021](../decisions/0021-her-treats-are-hers-to-edit.md)).
4. **The app**: eight pages, the stage, toasts and particles, the menu bar
   ([0022](../decisions/0022-closing-the-window-keeps-counting.md)), the
   welcome, the permission flow, an icon drawn with PIL.
5. **CI**, then fixes from its compiler.

## What looked broken and wasn't

- **"GitHub isn't running anything."** No workflow run appeared for half an
  hour and I asked the user to switch Actions on; it was already on. The
  workflow's `push:` trigger listed `tags:` and `paths:` but no `branches:`,
  and a push trigger that names only tags ignores every branch push. Adding
  `branches: ["**"]` fixed it.

## The icon

Drawn with PIL in the container: a 1024px rounded square, plum to magenta,
a gold fountain-pen nib, a lemon sparkle. The script is in this session's
transcript; redraw by the same recipe if it changes (`Resources/icon-1024.png`;
`make_app.sh` makes every size with `sips` and `iconutil`).

## Not done yet

- Never run on a real Mac by a person: proven by XCTest and snapshots on CI
  only. Watch for the event tap (Input Monitoring) on her Mac, the menu bar
  label, and `SMAppService` login items from an ad-hoc signed app.
- Ad-hoc signed: first launch needs Privacy & Security → Open Anyway, and
  Input Monitoring must be re-granted after each update. A paid Apple
  Developer ID and notarisation would remove both.
- Google Docs counts only by counting the whole browser.
- Could move to a repo of its own.
