# 0006 - Gear never shortens the clock

Diablo-style gear needs stats that matter. The obvious one for a battle pass
- "tiers come 10% faster" - would undo the point of the thing: the user wants
to be encouraged to spend *longer* making music.

So every affix and power rewards the work instead: more XP (from everything,
from MIDI, from recording, after an hour in a session, late at night), more
coins, better loot, bigger quest and check-in rewards, extra crate items,
more grace before counting as idle. A tier takes `G.TIER_SECONDS` of active
time whatever is equipped.
