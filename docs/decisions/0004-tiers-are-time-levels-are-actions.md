# 0004 - Tiers are time; levels are actions

The user asked for two things that could have been one bar: a reward every
fifteen minutes (a bigger one each hour), and XP from actions that unlocks
crates.

They are two tracks. The **season pass** fills only with active time, so its
promise - "fifteen more minutes and you get the next one" - is exact and can
be counted down on screen. The **level bar** fills with XP from everything
(four XP an active minute, plus tracks, items, notes, plugins, takes,
markers, quests, check-ins), and each level gives a crate. Editing XP is
capped at 120 a minute so it cannot be farmed by clicking.

Seasons are calendar months, as Fortnite has seasons: a 100-tier track, then
bonus tiers for ever. Only the track resets; the level, coins and everything
owned stay.
