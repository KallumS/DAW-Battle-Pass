# 0009 - Escape closes a celebration, not the window

In the sister repos Escape closes the window. Here closing the window stops
the clock, which costs the user progress, and Escape is the natural key for
"skip this".

So Escape skips or collects the reward on stage (opening a crate straight
away, collecting a revealed tier) and never closes the window. Enter presses
the stage's main button. The welcome is the one modal Escape leaves alone: it
gives the starter crate.
