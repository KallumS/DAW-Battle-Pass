# 0015 - Anything that spends or destroys asks once more

Buying a 12,000-coin pass, redeeming a pass, salvaging gear and deleting an
idea are all one click away in a busy window. The sister repos have nothing
that costs, so there was no house pattern.

`sure(id, label)`: the first click turns the button yellow and makes it say
"Sure?" for three seconds; a second click does it. Only one button can be
armed at a time. A dialog box was the alternative; it interrupts more and
looks nothing like the rest of the window.
