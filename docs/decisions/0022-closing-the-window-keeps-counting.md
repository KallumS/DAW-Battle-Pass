# 0022 - Closing the window keeps the clock running

DAW Battle Pass is a script whose clock stops when its window closes, which is
why Escape there never closes the window (0009). A writer works in another
app all day and shouldn't have to keep a game window open, so Writing Battle
Pass lives on in the menu bar when its window is closed - the pencil and the
time to the next tier - and only Quit stops it. Rewards won with the window
closed wait on the stage (a badge on the Dock icon counts them) and play when
she opens it. Escape still closes a celebration.
